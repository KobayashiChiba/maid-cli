# 机制说明（行为契约）

这里讲的是**"你发指令之后实际会发生什么"** —— 写自动化脚本前必须知道的副作用。
每条都按「你发什么 → 会发生什么 → 所以你该怎么做」写。

---

## 1. 唤醒制：不唤醒，她不存在

- **你发**：任何女仆指令
- **会发生**：没 `wake` 时她不在世界里（零加载票，实体没 tick），所有指令直接报 `not_awake`。
  `wake` 之后开始计时，**300 秒没有新指令就自动释放**
- **所以你**：每次开工先 `wake`；超过 5 分钟的脚本要在中间插一条指令续期（`sense self` 就行）

## 2. 自动寻路：够不着就自己走过去

- **你发**：`place` / `break` / `use` / `hit` / `open` / `take` / `put` / `move` / `pickup` / `ride`
- **会发生**：先算"站哪儿能够到"（`StandPoint`），够不到就**插队走位**过去；走位超时会让**传送到那个落脚点**再执行
- **所以你**：**不要**在这些指令前手动 `go`；`go` 只用于"我就是要她站在某处"（比如你要看她站在镜头里）

## 3. 到达判定：`go` 是 3 格，内部走位是 1 格

- `go` 的到达判定：水平距离 ≤ 3 格且 `|Δy| ≤ 1`（宽松，够用）
- 内部走位（给动作垫步）的判定：≤ 1 格（严格，因为落脚点是按几何算出来的）
- **所以你**：`go` 到地方后她可能差 1~2 格，别惊讶；要精确位置用 `tp`

## 4. 受控 = 切「指令模式」任务

- **你发**：`control`
- **会发生**：她的工作模式切成 `maid_cli:command` —— 不注册任何主动行为（不捡东西、不跟随、不随机游走），
  但她仍能听指令走位/挖放
- **所以你**：需要"她别乱动"时用 `control`；做完用 `control off=true` 还她自主

## 5. 切换模式会自动退出受控

- **你发**：`mode attack`（任何 `mode`）
- **会发生**：受控状态**自动解除**（因为换任务和"指令模式"是互斥的）
- **所以你**：`mode` 之后想继续受控，要重新 `control`

## 6. `control off` 会归队

- **你发**：`control off=true`
- **会发生**：除了还她自主，还会**传送到主人身边**
- **所以你**：别在远处收工；远程作业完要么保持受控，要么主人就在旁边

## 7. 会话：8 格、180 秒、走远自动关

- **你发**：`open`
- **会发生**：会话有距离和超时限制（默认 8 格内、180 秒）；她走远或超时会**自动关闭并退还余料**
- **所以你**：开箱→搬东西→关箱要一气呵成；别开着界面让她跑远

## 8. 动作队列：一次一个作业

- **你发**：连续两条写操作
- **会发生**：第二条排队，等第一条结束；`stop` 会清空整个队列
- **所以你**：别并发下单；要中断就 `stop`（会连会话一起关）

## 9. `ok` 只代表受理，结论在 history

- **你发**：`place ...`
- **会发生**：命令立刻返回 `{ok:true, id:N}`（受理），真正结果要等作业跑完写进 `sense state` 的 history
- **所以你**：脚本判成败要看 `history[N]` 的 `ok` / `failures`，或重新读世界（CLI 默认会等到完成）

## 10. 特殊动作的固有语义

| 动作 | 语义 |
|---|---|
| `break` | 走 TLM 的破坏流程（保留权限校验），掉落**手动弹回原位**；挖矿额外给经验球 |
| `place` | 自动从背包取方块换手；**不自动避让** —— 她站位挡住就报错，挪位是编排层的事 |
| `hit` | 伤害在**下一 tick** 生效，立刻读血量会看到旧值 |
| `use` | 放置型右键的作用格是"点击位置.relative(face)"，不是被点的方块本身 |
| `macro shoot` | 真蓄力（默认 20 tick）+ 自己造箭扣箭；解不出弹道就报错不硬射 |
| `ride` | 骑乘中位置由载具决定，**走位与传送全部失效** → 先 `macro dismount` |

## 11. 物品守恒

所有搬运走 `IItemHandler` 抽取/插入校验：不存在"从结果格白拿产物"。
关会话、走远、超时、服务端正常关闭都会把余料退回背包（塞不下掉地上）。
**例外**：虚拟槽只在内存，崩溃会丢（与原版一致），正常关闭不丢。
