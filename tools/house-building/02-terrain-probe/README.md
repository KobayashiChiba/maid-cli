# ② 地形勘察（选址）

在一片区域上采样，告诉你地表最高/最低点、起伏、最常见的方块 —— 用来决定平台铺在哪、铺多高。

**只读**：只发 `blocks` 查询，不动世界。

## 前置
- 服务端跑着、女仆已加载（或用 `--maid` 指定）

## 用法
```bash
python probe.py --center=-160,141,30 --radius 12 --step 3 --maid A1B2C3
python probe.py --maid A1B2C3            # 不给 --center 就用她脚下
```

## 参数
| 参数 | 默认 | 说明 |
|---|---|---|
| `--center` | 她所在格 | 中心点，`x,y,z`（负数用 `--center=-160,141,30` 等号写法）|
| `--radius` | 12 | 半径（格）|
| `--step` | 3 | 采样步长（格）—— 步长越小越准、越慢 |
| `--y-range` | `-8 8` | 相对中心点的竖向搜索范围 |

## 输出
地表高度区间、最常见高度、方块分布，以及一句「铺平台建议」：
```
地表高度：最高 140 @(-154,24) · 最低 132 @(-166,24) · 起伏 8 格
铺平台建议：底面取 y=141（最高点之上），覆盖 x -166~-154 · z 24~36
```

## 限制
- 逐点查询，`半径/步长` 决定耗时：半径 16 + 步长 2 ≈ 289 点，约 1 分钟
- 只看表面方块，不做洞穴/悬空结构分析
